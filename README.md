# 🐍 Python Projects

Projetos desenvolvidos durante meus estudos para Certificação em Python da freeCodeCamp. Este repositório é dedicado aos projetos desenvolvidos e meu aprendizado contínuo, com foco em prática, resolução de problemas e desenvolvimento de aplicações reais.

## 📋 Sobre
 
Este repositório reúne projetos criados ao longo da minha jornada de aprendizado em Python, incluindo exercícios, desafios e aplicações desenvolvidas durante cursos e certificações.

O objetivo é consolidar conhecimentos em:
 
- Lógica de programação
- Estruturas de dados
- Programação orientada a objetos (POO)
- Manipulação de arquivos
- Automação de tarefas
- Boas práticas de desenvolvimento
- Controle de versão com Git e GitHub

### Projetos de Certificação

- Criar um gerenciador de configuração de usuário
- Criar um app de orçamento
- Construir uma calculadora de área de polígono
- Construir uma tabela hash
- Implementar o algoritmo da torre de Hanoi
